## Original visual thesis

The diagram explains enterprise configuration inheritance through five explicit scopes: enterprise, data, analytics, operations and project. The project configuration is the focal artifact; each enclosing ring contributes one inherited artifact. The nested geometry itself is the index, so ordinary semantic arrow connectors are intentionally absent.
