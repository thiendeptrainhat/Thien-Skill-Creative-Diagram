# P-18 / P-19 — auxiliary comparison view

User request: view all approved P-18 and current P-19 diagrams together for comparison.
This directory is a viewing aid, not a new gallery candidate, phase transition,
owner approval, golden, runtime change or P-19C execution.

## Design contract

- Route: auxiliary static HTML comparison sheet; restrained executive-artifact
  principles with web, reference-preservation and accessibility modules.
- Audience/job: owner compares the approved design direction against all current
  P-19 specimens without switching mode tabs.
- Preserve: exact P-18R6 review-17 SVGs and P-19B review-01 source HTML;
  all diagram geometry, text, colors, typography roles and paint order.
- Extend only: a quiet warm-paper viewer, grouped into 14 engine sections;
  sticky P-18 reference at left and all three P-19 modes at right on desktop.
  A native checkbox enlarges the diagrams without hiding any; mobile stacks them.
- Hierarchy: candidate identities/status, scope caveat, engine navigation,
  approved reference, current type/capability and modes, original source links.
- All 14 + 129 previews are present and visible. There are no filters or collapsed
  mode panels. Click a diagram to open its source HTML, including semantic tables.
- Viewer typography follows the existing local Georgia/Avenir Next/Menlo stack.
  No new font, dependency, external asset, motion or network request is introduced.
- Native links/checkbox, visible keyboard focus, skip link, explicit status text,
  image alternatives, fluid layout and print rules. No accessibility certification.
- Comparison is by engine, not identical input: P-18 anchors and P-19 fixtures have
  different scenarios, complexity and data. Current P-19 is not owner-approved.

## Preview fidelity

P-18 images embed the exact standalone SVG bytes. P-19 images extract the exact
inline SVG and insert the original base stylesheet into the SVG. Only the page's
responsive/print/reduced-motion media blocks are omitted: their `min-width:760px`
rule is for scrolling a standalone page, not for a scaled preview. SVG namespace
and intrinsic width/height are supplied from the original viewBox. No diagram
element, geometry, text, color value or font declaration is rewritten.
The SVG image boundary isolates IDs and CSS from other diagrams and the viewer.

## Verification / limits

Run from repository root:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 evidence/p19/comparison/generate_comparison.py
PYTHONDONTWRITEBYTECODE=1 python3 evidence/p19/comparison/generate_comparison.py --check
```

The generator verifies pinned source manifests and their current P-18/P-19B file
hashes, exact coverage, original links, inert SVG payloads and source preservation.
`--check` compares the generated bytes without writing. `COMPARISON-MANIFEST.json`
records every input and embedded preview hash, plus static check results.

Browser verification is **blocked / not executable**: the existing local-file
browser operation was rejected by the browser URL policy. No server, alternate
browser or other bypass is used. Desktop/mobile rendering, keyboard behavior,
image loading and actual font resolution remain unverified in-browser.

Historical rejected candidates are intentionally excluded. Original gallery,
canonical renderer, governance, packages, publication mirror and Release are not
changed. The UI/UX skill guides only the auxiliary viewer, not a diagram redesign.
