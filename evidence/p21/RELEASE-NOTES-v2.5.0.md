## Known limitations and release controls

- PNG output remains conditional on a host-provided rasterizer; the skill does not install one automatically.
- Host integrations classified as conditional are not advertised as universally supported.
- Product release `2.5.0` does not mechanically rename independent internal schemas and protocols such as semantic `1.5` or structural renderer/job `2.1`.
- Package build, `dist` promotion, Git commit/tag and GitHub Release publication require separate owner authorizations after their respective gates pass.
- This private candidate grants no usage rights by access or download alone. G-06 must bind exact legal/brand/provenance bytes and record counsel approval or an explicit owner risk-accepted waiver.
